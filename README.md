## Holiday Configuration

The schedule tracker uses a `holidays.json` file to automatically populate holidays in the schedule.

### Holiday Types

The JSON file contains two types of holidays:

1. **Regular Holidays** - Fixed dates that occur every year (e.g., New Year's Day, Independence Day, Christmas)
2. **Floating Holidays** - Holidays that change dates each year (e.g., Chinese New Year, Maundy Thursday, Good Friday, National Heroes Day)

### File Location

The `holidays.json` file must be located in the same directory as the `create.schedule.ps1` script.

### File Format Example

```json
{
  "regularHolidays": [
    {
      "month": 1,
      "day": 1,
      "name": "New Year's Day"
    }
  ],
  "floatingHolidays": [
    {
      "month": 4,
      "day": 2,
      "name": "Maundy Thursday"
    }
  ]
}
```

### ⚠️ IMPORTANT: Annual Update Required

**Floating holidays MUST be updated every year** as their dates change annually. Before generating schedules for a new year:

1. Open `holidays.json` in a text editor
2. Update the `month` and `day` values for all floating holidays:
   - **Chinese New Year** - Varies based on lunar calendar (usually January or February)
   - **Maundy Thursday** - Thursday before Easter (varies by year)
   - **Good Friday** - Friday before Easter (varies by year)
   - **National Heroes Day** - Last Monday of August (varies by year)
3. Save the file before running the script

### How It Works

When the script runs, it:
- Reads the `holidays.json` file
- Checks each date in the schedule
- If a date matches a holiday AND falls on a **weekday (Monday-Friday)**, it automatically populates the cell with "H" for all employees
- Weekends are not affected by holiday configuration

### Example

If December 25, 2025 falls on a Thursday (weekday), all employees will automatically have "H" populated for that day in their schedule. If it falls on a Sunday, no "H" will be populated since it's already a weekend.
